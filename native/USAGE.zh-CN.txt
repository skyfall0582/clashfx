ClashFx 0.2.10 · GPUI 原生版

安装
双击 ClashFx-0.2.10-x64-Setup.exe，按提示安装。默认创建桌面和开始菜单快捷方式，无需管理员权限。
安装包已签名并附带运行所需文件。重新安装或卸载前，请从系统托盘退出 ClashFx。
卸载会移除程序与快捷方式，保留订阅和设置。

启动
双击 ClashFx.exe，mihomo.exe 和 geodata 文件夹需要保留在同一文件夹。
安装包附带 GeoIP、GeoSite 和 ASN 数据，规则模式首次启动无需先联网下载这些数据库。已有有效数据库会保留；不完整的下载会备份后用随包数据修复。
“设置 → 开机自启”默认关闭。开启后，登录 Windows 时自动启动当前程序并使用当前配置目录；关闭后立即取消。自启不会自动开启系统代理。移动程序后请重新开关此选项以更新启动位置。

日常使用
1. 在“订阅池”导入 Clash / Mihomo YAML 链接或本地文件。导入和编辑均可填写多行备注，记录网站、平台及使用信息；更新订阅时保留备注。
2. 右上角“导入订阅”打开弹窗，填写信息后点击橙色主按钮确认；取消为次要操作，Esc 关闭。卡片显示单行备注预览，支持按完整备注搜索；链接只显示域名，完整地址可复制或在编辑时查看。编辑和更新使用图标；删除位于编辑弹窗左下角，需再次确认。
3. 有可用节点时，内核会随应用启动；导入订阅后也会自动准备。点击“连接”页的当前节点名称，或订阅卡片上无边框、无底色的“节点图标 + 数量 + 右箭头”入口，进入节点选择。
4. 在“连接”开启“系统代理”即可让遵循 Windows 代理设置的应用使用当前分流方式。
5. 内核未就绪时，系统代理开关会先启动内核，启动成功后才接管代理。关闭系统代理后，内核仍可用于测速和手动配置本地代理的应用。
   Codex 等应用通过环境变量指定的本地代理也会自动接入，无需修改应用配置。若提示端口被占用，请先退出其他代理软件再开启；关闭系统代理后会释放这些兼容端口。
6. 代理节点顶部用可搜索下拉框筛选订阅，长名称会在列表中完整换行显示，右上角仪表图标用于测速，只更新延迟，不改变当前节点。
7. 网络图形点亮并持续流动表示代理运行；警示图标表示异常。系统代理关闭或使用直连模式时不显示代理流动。流动是状态动画，不代表实际流量。

分流方式
默认使用规则模式。在“设置”选择规则、全局或直连，运行中直接生效。
规则模式默认使用首个提供 rules 的订阅，也可指定其他订阅的规则。直连与拦截规则保留，需代理的流量使用当前节点，仍可自动切换。
切换节点或备用订阅不会改变规则来源。订阅不含规则时，会明确提示“本地网络直连，其余流量使用代理”。
全局模式全部走当前节点；直连模式全部直接连接，并暂停自动故障切换。订阅规则可能需要下载相应规则集或地理数据库。

日志
应用事件和 Mihomo 日志合并显示，保留启动信息、警告、错误及连接详情。顶部筛选固定，仅记录区域滚动，右侧滚动条可拖动。
订阅更新失败短时提示，自动收起后可在日志中查看。
可按全部、警告、错误筛选，并搜索关键词；右上角图标复制当前筛选结果或清空列表。

配置自动切换
首页显示池内各节点的检测状态、可用数量及最近的切换去向；未检测和过期结果不会计入可用。全部不可用时明确提示并显示重试时间。
1. 打开“自动切换 → 切换池”。左侧是可添加的订阅与节点，右侧是自动切换池。
2. 点击绿色右箭头将节点放入右侧，点击红色减号放回左侧；整组操作使用“图标 + 全部添加 / 全部移出”。服务器图标旁的数字表示节点数量。
3. 右侧从上到下为优先顺序。拖动订阅或节点前的拖动柄调整，也可按 Alt + 上/下方向键。
4. 在“检测规则”修改连续失败次数、检测超时、当前节点检查间隔和自动切回选项。
5. 只有右侧池内的节点会参与自动切换，不再需要额外填写地区。新导入的节点默认不加入池。
6. 清空切换池会停止自动选节点并保留当前连接。手动连接可使用任意已导入节点，不改变切换池。
7. 池非空时，手动选择默认保持五分钟，可点“恢复自动”立即结束。

订阅管理
修改链接会先下载验证；失败保留原链接和缓存。本地文件可替换，保留订阅身份及节点选择。
重复链接会提示已有订阅，同名导入自动区分。Ctrl+S 保存当前编辑，关闭应用前请保存。
切换池两栏分别搜索。搜索期间“添加匹配”和“移出匹配”仅作用于搜索结果。

切换逻辑
连续代理连接失败 → 同步检测当前节点与备用节点 → 当前节点检测失败后切换到可用备用。
当前节点健康时保持连接，平时只检查当前节点，备用节点按需检测；启动时也优先保留上次使用的可用节点。默认不自动切回优先节点，可在“检测规则”开启。手动选择默认保持五分钟，可点击“恢复自动”立即结束。
所有池内节点都不可用时保留代理路由并稍后重试，不会擅自使用池外节点或改为直连。

入口自动修复
仅在当前节点连通性检测失败时查询多个 DNS，并通过实际代理连接验证候选地址；备用节点失败不会触发入口修复。应用前再次检查当前连接，已经恢复则保持原入口，不重载配置。未找到可用地址时保留当前配置并稍后重试。
手动选择的节点也会检测，不要求加入切换池。订阅域名变更后重新发现入口；不会修改订阅原文件或系统 hosts，也不会使用其他用户固定的 IP。直连模式和停止内核时暂停修复。
当前支持域名型入口；直接填写 IP 或通过 dialer-proxy 连接的节点继续使用原有故障切换。

默认设置
30 秒内连续失败 3 次后检测；每个节点的检测地址和复检共用 3 秒总预算。快速失败时在剩余预算内复检，不再额外等待 2 秒。故障切换按订阅优先级查找备用，找到可用节点就切换，不等待其余慢节点。
每 5 分钟检查当前节点；连接失败日志会提前触发检查。默认不自动切回；开启后，切回冷却 60 秒、恢复连续通过 3 次才切回，真正故障时的应急切换不受切回冷却限制。
远程订阅每天检查更新，内容未变化时不重载内核或重新检测。更新失败保留缓存，1 小时后重试；仍可手动更新。新增或改名节点需要手动加入池。
已移除的池内节点会标记“已失效”，可直接移出。

运行与退出
点窗口右上角叉号后留在系统托盘，代理与监测继续运行。点击托盘图标或再次启动程序可重新打开窗口。
右键系统右下角的 ClashFx 图标，选择“退出”后，会先恢复系统代理，再停止内核与兼容端口，完成后才退出；恢复失败时保留程序与内核并提示原因。
主进程意外退出时，Windows 会结束它启动的内核，独立恢复进程会还原本次接管的系统代理。恢复到启动前的代理设置；若其他软件已接管，则保留其他软件的设置。
可在“设置”打开配置目录。请自行保管其中的订阅地址和节点凭据。

当前范围
已实现 GPUI 界面、订阅管理、切换池、自动故障转移、恢复、手动控制、日志和 Windows 系统代理。
支持包含 proxies 列表的 YAML。仅含 proxy-providers、URI 或 Base64 的订阅需先导出为包含节点的 Clash YAML。
当前不支持 TUN / 服务模式、WebDAV 和扩展脚本。

旧版本升级
原来的节点选择与地区筛选会合并为切换池，保留原先允许自动使用的范围。
原先停用的订阅可直接手动使用，但不会自动加入池。
升级前的配置会备份为 settings.v1.backup.json；退回旧版时需要使用该备份。
原默认 4 秒或 8 秒超时会改为 3 秒总预算，其他自定义超时保留。v1/v2 配置同时关闭自动切回，将原默认 60 秒检查改为 300 秒；v3 配置保留这些选项。升级前按原版本备份为 settings.v2.backup.json 或 settings.v3.backup.json，退回旧版前需恢复对应备份。升级后仍可自行修改检测规则。
